# Tropa Movie Database

Website for reviewing movies watched on Discord with friends. Uses the TMDB - The Movie Database API to search for movies.

# Features

## Movie Search

Using the TMDB API, you can search for movies and mark them as watched.

## Movie Rating

After marking a movie as watched, you can rate it with stars from 1 to 10. This rating is saved and shown to other users.

## List of Rated Movies

All previously rated films appear on the home page, and when you click on them, a modal with all the ratings is displayed.
